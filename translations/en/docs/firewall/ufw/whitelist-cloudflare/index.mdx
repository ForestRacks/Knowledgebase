---
title: Whitelist Cloudflare IPs in UFW Firewall on Ubuntu
toc: Whitelist Cloudflare (UFW)
description: Allow only Cloudflare IP addresses through UFW for ports 80 and 443. Ready-to-use bash script that fetches current Cloudflare IPv4 and IPv6 ranges.
---

Run the following script:
```bash:cffw.sh
#!/bin/sh

curl -s https://www.cloudflare.com/ips-v4 -o /tmp/cf_ips
echo "" >> /tmp/cf_ips
curl -s https://www.cloudflare.com/ips-v6 >> /tmp/cf_ips

# Allow all traffic from Cloudflare IPs (no ports restriction)
for cfip in `cat /tmp/cf_ips`; do ufw allow proto tcp from $cfip to any port 80,443 comment 'Cloudflare IP'; done

ufw reload > /dev/null
```
