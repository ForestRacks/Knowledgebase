---
title: Use Biometric Fingerprint Authentication for Sudo
description: Learn how to use fingerprint authentication instead of typing your password every time you use sudo.
---

Sometimes typing your password in terminal gets excessive every single time you want to use sudo. You can skip this process and use fingerprint authentication instead by following this guide.

<Stepper>
<StepperItem title="Open Pam File">
```
sudo nano /etc/pam.d/sudo
```

</StepperItem>
<StepperItem title="Add Line">
```
auth       sufficient     pam_tid.so
```
</StepperItem>
</Stepper>
