title: Change an Application Icon in MacOS
description: Welcome to the ForestRacks help center! Here, you will find comprehensive guides, tutorials, and reference materials to effectively utilize ForestRacks services.
---

1) Open the Applications folder
2) Right click the application that you want to change the icon of
3) Click "Get info" in the menu that appears
4) Drag and drop new image top left in the preview image of the get info window.
