---
title: Install PHP Composer on Linux
toc: Install Composer
description: Install Composer dependency manager globally on Linux servers. Run composer install for PHP project dependencies with autoloader optimization.
---
Composer is a dependency manager for PHP that allows developers to easily ship dependencies required to operate a PHP applications.

```bash
curl -sS https://getcomposer.org/installer | sudo php -- --install-dir=/usr/local/bin --filename=composer
```

Change to the directory containing `composer.json` and install dependencies:
```bash
composer install --no-dev --optimize-autoloader
```
