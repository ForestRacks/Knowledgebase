---
title: Enable Automatic Security Updates on Linux
description: Configure unattended-upgrades on Ubuntu/Debian or dnf-automatic on CentOS/RHEL. Includes cron job setup for scheduled system updates.
---

<Tabs defaultValue="debian" className="pt-5 pb-1">
  <TabsList>
    <TabsTrigger value="debian">Ubuntu/Debian</TabsTrigger>
    <TabsTrigger value="rhel">CentOS/RHEL</TabsTrigger>
  </TabsList>
  <TabsContent value="debian">
    ## Using the automatic updates package
    ```bash
    apt install unattended-upgrades
    ```

    ## Using Cronjobs
    First install cron:
    ```bash
    apt install cron
    ```
    Add the cronjob:
    ```bash
    (crontab -l ; echo "30 16 * * 1,3,6 apt update && apt upgrade -y")| crontab -
    ```
  </TabsContent>
  <TabsContent value="rhel">
    ## Using the automatic updates package
    First install dnf:
    ```bash
    yum install dnf
    ```
    Then install the automatic updates package:
    ```bash
    dnf install -y dnf-automatic
    ```

    ## Using Cronjobs
    First install dnf and cron:
    ```bash
    yum install dnf cron
    ```
    Add the cronjob:
    ```bash
    (crontab -l ; echo "30 16 * * 1,3,6 dnf update -y")| crontab -
    ```
  </TabsContent>
</Tabs>
