---
title: How To Install MariaDB on Ubuntu and Debian
toc: Install MariaDB
description: Install MariaDB database server on Ubuntu and Debian Linux using the official repository. Simple two-step installation with apt package manager commands.
---

<Stepper>
<StepperItem title="Running Installer">
```bash
# MariaDB repo setup script can be skipped on Ubuntu 22.04
curl -sS https://downloads.mariadb.com/MariaDB/mariadb_repo_setup | sudo bash
```

</StepperItem>
<StepperItem title="Adding Package">
```bash
apt install mariadb-server
```
</StepperItem>
</Stepper>
