To fix corruption in MySQL databases or tables, here are a couple methods you can try. Please note that data corruption isn't fool proof and won't always work. Here at ForestRacks we generally take daily backups of all customer products so if recovery fails, don't hesitate to [Contact Us](/docs/about/contact) and we will see what we can do.

## Recover a MySQL Table

### Optimize Table
In this example, the database is called `billing` and the table is called `statements`.
<Stepper>
<StepperItem title="Enter the MySQL shell">
```bash
mysql
```
</StepperItem>
<StepperItem title="Select the `billing` database">
```sql
use billing;
```
</StepperItem>
<StepperItem title="Run the optimize command on your corrupted table">
```sql
OPTIMIZE TABLE statements;
```
</StepperItem>
</Stepper>

### Replace Table
If all else fails, you might have to delete the table and create a new one like it, note this is a last resort and deletes all data from the table, so before you resort to this solution, confirm with ForestRacks support if there is a backup of your database:
```sql
CREATE TABLE new_statements LIKE statements;
# Insert the data from the corrupted table into the new table:

INSERT INTO new_statements SELECT * FROM statements;
# Once the data is successfully copied, you can drop the old statements table and rename the new table:

DROP TABLE statements;
RENAME TABLE new_statements TO statements;
# This recreates the statements table with the copied data.
```

## Recover a MySQL Database
<Stepper>
<StepperItem title="Enter Recovery Mode">
1) Open the MySQL configuration `my.cnf` file using a text editor like nano or vim.
2) Add text below to the bottom of the file:
```ini:my.cnf
[mysqld]
innodb_force_recovery = 1
```
</StepperItem>
<StepperItem title="Restart MySQL">
<Tabs defaultValue="mariadb" className="pt-5 pb-1">
  <TabsList>
    <TabsTrigger value="mariadb">MariaDB</TabsTrigger>
    <TabsTrigger value="mysql">MySQL</TabsTrigger>
  </TabsList>
  <TabsContent value="mariadb">
    ```bash
    systemctl restart mariadb
    ```
  </TabsContent>
  <TabsContent value="mysql">
    ```bash
    systemctl restart mysql
    ```
  </TabsContent>
</Tabs>
</StepperItem>
</Stepper>
