This guide will walk you through the process of setting up a bastion server using WireGuard for secure communication and SSH keys for authentication. Additionally, we will use UFW (Uncomplicated Firewall) to specify firewall rules for enhanced security. Follow the steps below to create your bastion server.

### Prerequisites
Before proceeding with the setup, ensure that you have the following:
* A Linux Dedicated Server or VPS running a compatible distribution (e.g., Ubuntu, Debian).
* Root access to the VPS or Dedicated Server.

<Stepper>
<StepperItem title="Install WireGuard">
1) Connect to your server/VPS via SSH using your preferred terminal emulator or command prompt.
2) Update the package manager's repositories:
```bash
apt update
```
3) Install WireGuard:
```bash
apt install wireguard
```
4) Verify that WireGuard is installed successfully:
```bash
wg --version
```
</StepperItem>
<StepperItem title="Generate SSH Key Pair">
1) On your local machine, open a terminal or command prompt.
2) Generate an SSH key pair using the `ssh-keygen` command:
```bash
ssh-keygen -t rsa -b 4096 -f ~/.ssh/bastion_key
```
This command generates a 4096-bit RSA key pair and saves it to ~/.ssh/bastion_key on your local machine.
3) Copy the public key to the server/VPS:
```bash
ssh-copy-id -i ~/.ssh/bastion_key.pub username@bastion-server
```
Replace `username` with your server's username and `bastion-server` with the hostname or IP address of your bastion server. Enter the server's password when prompted.
```bash
ssh -i ~/.ssh/bastion_key username@bastion-server
```
If successful, you should be logged in to the bastion server without entering a password.
</StepperItem>
<StepperItem title="Configure WireGuard">
1) On the bastion server, create a WireGuard configuration file:
```bash
nano /etc/wireguard/wg0.conf
```
Use the following template as a starting point:
```ini:wg0.conf
[Interface]
Address = 10.0.0.1/24
ListenPort = 51820
PrivateKey = <BASTION_PRIVATE_KEY>

[Peer]
PublicKey = <CLIENT_PUBLIC_KEY>
AllowedIPs = 10.0.0.2/32
```
Replace `<BASTION_PRIVATE_KEY>` with the private key generated during WireGuard installation and `<CLIENT_PUBLIC_KEY>` with the public key generated on your local machine.
2) Save and close the file (Ctrl+O, Enter, Ctrl+X).
3) Start the WireGuard service:
```bash
systemctl start wg-quick@wg0
```
Enable automatic start on boot:
```bash
systemctl enable wg-quick@wg0
```
```bash
systemctl status wg-quick@wg0
```
The status should indicate that the service is active.
</StepperItem>
<StepperItem title="Configure UFW Firewall">
1) Enable UFW (if not already enabled):
```bash
ufw enable
```
2) Allow incoming SSH connections on the bastion server:
```bash
ufw allow 22/tcp
```
3) Allow WireGuard connections:
```bash
ufw allow 51820/udp
```
4) Set default policies to deny incoming and allow outgoing:
```bash
ufw default deny incoming
ufw default allow outgoing
```
5) Reload UFW to apply the rules:
```bash
ufw reload
```
6) Verify the firewall rules:
```bash
ufw status verbose
```
You should see rules allowing SSH (port 22) and WireGuard (port 51820).
</StepperItem>
<StepperItem title="Test the Connection">
1) On your local machine, create a WireGuard client configuration file:
```bash
nano ~/wg-client.conf
```
2) Add the following configuration:
```ini:wg-client.conf
[Interface]
Address = 10.0.0.2/24
PrivateKey = <CLIENT_PRIVATE_KEY>

[Peer]
PublicKey = <BASTION_PUBLIC_KEY>
Endpoint = <BASTION_IP>:51820
AllowedIPs = 10.0.0.0/24
PersistentKeepalive = 25
```
Replace `<CLIENT_PRIVATE_KEY>` with your client's private key, `<BASTION_PUBLIC_KEY>` with the bastion server's public key, and `<BASTION_IP>` with your bastion server's public IP address.
3) Start the WireGuard connection:
```bash
wg-quick up ~/wg-client.conf
```
4) Verify the connection is active:
```bash
wg show
```
5) Test SSH access through the VPN:
```bash
ssh -i ~/.ssh/bastion_key username@10.0.0.1
```
If successful, you're now connected to your bastion server through the secure WireGuard tunnel.
</StepperItem>
<StepperItem title="Secure SSH Access">
1) On the bastion server, edit the SSH configuration:
```bash
nano /etc/ssh/sshd_config
```
2) Make the following changes to enhance security:
```bash
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes
AllowUsers username
```
Replace `username` with your actual username.
3) Restart the SSH service:
```bash
systemctl restart sshd
```
4) Verify SSH is running:
```bash
systemctl status sshd
```
</StepperItem>
</Stepper>

### Best Practices

* **Regular Updates**: Keep your bastion server and WireGuard installation up to date with security patches.
* **Key Rotation**: Periodically rotate SSH keys and WireGuard keys for enhanced security.
* **Monitoring**: Set up logging and monitoring to detect unauthorized access attempts.
* **Backup Configuration**: Keep backups of your WireGuard and SSH configurations.
* **Limit Access**: Only allow trusted IP addresses to connect to your bastion server when possible.

### Troubleshooting

**WireGuard Connection Issues:**
* Verify that port 51820/udp is open on your firewall and router
* Check that the keys are correctly configured in both client and server configurations
* Ensure the endpoint IP address is correct

**SSH Connection Issues:**
* Verify SSH keys are properly installed with `ssh-add -l`
* Check SSH logs with `journalctl -u sshd`
* Ensure the correct private key is being used with the `-i` flag

**UFW Blocking Connections:**
* Check UFW status with `ufw status verbose`
* Temporarily disable UFW for testing with `ufw disable` (re-enable after testing)
* Review UFW logs at `/var/log/ufw.log`

Your bastion server is now configured and ready to provide secure access to your infrastructure. All connections will be encrypted through WireGuard, and authentication will be handled via SSH keys.
