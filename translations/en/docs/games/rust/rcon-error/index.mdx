---
title: Waiting for RCON to come up... Error
description: Learn how to fix the "Waiting for RCON to come up..." error.
---

When you receive this error it means one of two things either that the server is still booting or if continues, there are not 2 allocated ports on your server and you must open a ticket to get this fixed. The other way to check it is to see what your rcon port is and make sure that it lines up with the port in the oxide.config or else rcon wont load and your server will end up crashing.
