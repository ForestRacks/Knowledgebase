---
title: How to Enable Keep Inventory
description: Learn how to enable the Keep Inventory feature in Minecraft.
---

Execute the following GameRule command in every world, generally people just have an overworld, nether, and end.

<Stepper>
<StepperItem title="Enable Keep Inventory in The Overworld">
```bash copy
/world world
/gamerule keepInventory true
```

</StepperItem>
<StepperItem title="Enable Keep Inventory in The Nether">
```bash copy
/world world_nether
/gamerule keepInventory true
```

</StepperItem>
<StepperItem title="Enable Keep Inventory in The End">
```bash copy
/world world_the_end
/gamerule keepInventory true
```
</StepperItem>
</Stepper>
