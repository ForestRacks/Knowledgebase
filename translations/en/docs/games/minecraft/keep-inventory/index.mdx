---
title: Enable Keep Inventory Gamerule in Minecraft
toc: Keep Inventory
description: Set keepInventory true in all dimensions (Overworld, Nether, End) so players keep items on death. Commands for Bukkit and vanilla servers.
---

Execute the following GameRule command in every world, generally people just have an overworld, nether, and end.

<Stepper>
<StepperItem title="Enable Keep Inventory in The Overworld">
```bash
/world world
/gamerule keepInventory true
```

</StepperItem>
<StepperItem title="Enable Keep Inventory in The Nether">
```bash
/world world_nether
/gamerule keepInventory true
```

</StepperItem>
<StepperItem title="Enable Keep Inventory in The End">
```bash
/world world_the_end
/gamerule keepInventory true
```
</StepperItem>
</Stepper>
