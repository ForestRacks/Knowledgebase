## New Mod System (As of January 29, 2025)

The recommended way to manage maps and mods is now through Pavlov RCON, which provides a user-friendly interface for server management.

### Using Pavlov RCON

<Stepper>
<StepperItem title="Access Pavlov RCON">
Go to [Pavlov RCON](https://pavlovrcon.com/login) and log in with your server credentials.
</StepperItem>
<StepperItem title="Navigate to Server Config">
Click on the "Server Config" tab after logging in.
</StepperItem>
<StepperItem title="Add Map Rotation">
Enter your UGC ID (format: UGC123456) and click "Rotate Map".
</StepperItem>
<StepperItem title="Remove Standard Maps">
Important: Remove the standard map from rotation to prevent it from defaulting back to SND (Search and Destroy).
</StepperItem>
<StepperItem title="Install RCON Plus (Recommended)">
Navigate to the Menu tab and install RCON Plus to give moderators enhanced control capabilities.
</StepperItem>
</Stepper>

### Using Custom Commands

Alternatively, you can use RCON commands directly:

**For Mods:**
```
UGCAddMod <UGC-ID>
UGCRemoveMod <UGC-ID>
```

**For Maps:**
```
AddMapRotation <UGC-ID>
```

For a complete list of RCON commands, visit the [Pavlov Wiki RCON Overview](https://pavlovwiki.com/index.php/Rcon_Overview_and_Commands).

## Legacy Map Configuration

The legacy method involves editing the Game.ini file directly. This method still works but the Pavlov RCON method above is now preferred.

<Stepper>
<StepperItem title="Log Into The Panel">
First login on [https://panel.forestracks.com](https://panel.forestracks.com) and click on your server. If you cannot login, follow the [Troubleshooting Guide](/docs/games/troubleshoot/invalid-login).
</StepperItem>
<StepperItem title="Locate File Manager">
Next click the "File Manager" panel tab
</StepperItem>
<StepperItem title="Open The Game.ini">
Open your `Game.ini` configuration file in `Pavlov/Saved/Config/LinuxServer/`
</StepperItem>
<StepperItem title="Add The New Map">
At the bottom of the file, add a new map like `MapRotation=(MapId="SVR_John_Bestbuy", GameMode="SND")`, here's an  example:
```ini:Game.ini showLineNumbers {6}
...
LimitedAmmoType=2
TickRate=90
TimeLimit=60
MapRotation=(MapId="sand", GameMode="DM")
MapRotation=(MapId="SVR_John_Bestbuy", GameMode="SND")
```

</StepperItem>
<StepperItem title="Reboot">
Click the "Reboot" button on the "Console" panel tab
</StepperItem>
</Stepper>

## Downloading Maps
<Tabs defaultValue="pc" className="pt-5 pb-1">
  <TabsList>
    <TabsTrigger value="pc">Pavlov PC</TabsTrigger>
    <TabsTrigger value="shack">Pavlov Quest</TabsTrigger>
  </TabsList>
  <TabsContent value="pc">
    If you use Standard PC or Beta PC, you can either use maps from [the Steam Workshop](https://steamcommunity.com/workshop/about/?appid=555160) or the new recommended [mod.io](https://mod.io/g/pavlov) site.

    If you use maps from the Steam Workshop, The `MapId` should start with "UGC" and look like `UGC######`. Find the map you want in the workshop. For example, notice the URL for Mirage ([https://steamcommunity.com/sharedfiles/filedetails/?id=2670152485](https://steamcommunity.com/sharedfiles/filedetails/?id=2670152485)). The 10 numbers at the end of the URL are what you need, so `UGC2670152485` would be the MapId for Mirage.

    If you use maps from mod.io, the method is very similar, you still start the MapId with UGC except rather than getting the ID number from the URL, you will see it listed as the "Resource ID" on the map page.

    Here's an example of what the MapId in your Game.ini will look like for PC:
    ```ini:Game.ini showLineNumbers {6}
    ...
    LimitedAmmoType=2
    TickRate=90
    TimeLimit=60
    MapRotation=(MapId="sand", GameMode="DM")
    MapRotation=(MapId="UGC1758245796", GameMode="GUN")
    ```
  </TabsContent>
  <TabsContent value="shack">
    If you use Shack RC or Shack Live, using maps is a bit more complicated, you first need to download **an up-to-date version** of the map from a reputable source like the creator, the channel in Horde's discord, or the channel in Arctic's discord. Then you have to upload and extract the map to `Pavlov/Saved/maps/` on your ForestRacks `File Manager` panel tab and finally list the map at the bottom of your `Game.ini` using the method mentioned on [Configuration](/docs/games/pavlov/adding-maps#configuration).

    Note: Outdated maps will not work, Shack Live maps are Unreal Engine 4.21 from November 2022 to March 2023 and Shack Live maps are Unreal Engine 4.27 from April 2023 or newer. To confirm you have the correct version, you can open the `metadata.json` file in the map folder and you should see something like `"EngineVersion": "4.27"`. Your server will also default to the "datacenter" map if the map you try is outdated or broken.
  </TabsContent>
</Tabs>

* KOTH - King of The Hill

* SND - Search and Destroy

* TDM - Team Death Match
* TTT - Trouble in Terrorist Town
* WW2GUN - WW2 Gun Game
* ZWV - Zombie Wave Survival
* HIDE - The Hidden
* INFECTION - Hidden Infection
* PUSH - Push
