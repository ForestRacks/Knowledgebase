---
title: Changing Server Names
description: Learn how to change the name of your Pavlov server.
---

<Stepper>
<StepperItem title="Log into Panel">
First login on [https://panel.forestracks.com](https://panel.forestracks.com) and click on your server. If you cannot login, follow the [Troubleshooting Guide](/games/troubleshoot/invalid-login).
</StepperItem>
<StepperItem title="Locate File Manager">
Next click the "File Manager" panel tab
</StepperItem>
<StepperItem title="Open the Game.ini">
Open your `Game.ini` configuration file in `Pavlov/Saved/Config/LinuxServer/`
</StepperItem>
<StepperItem title="Change the Server Name">
Modify `ServerName="[Hosted by ForestRacks.com]"` to your desired name like:
```ini filename="Game.ini" {3} copy
[/Script/Pavlov.DedicatedServer]
bEnabled=true
ServerName="Example's Pavlov Server"
MaxPlayers=10
...
```
</StepperItem>
<StepperItem title="Reboot">
Click the "Reboot" button on the "Console" panel tab
</StepperItem>
</Stepper>
