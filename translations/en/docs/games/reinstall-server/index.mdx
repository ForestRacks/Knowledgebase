---
title: Reinstall Game Server from Scratch
toc: Reinstall Server
description: Complete guide to reinstall your game server with backup creation and clean installation. Fix corrupted files or start fresh with new settings.
---
<Stepper>
<StepperItem title="Login to Panel">
First login on [https://panel.forestracks.com](https://panel.forestracks.com) and click on your server. If you cannot login, follow the [Troubleshooting Guide](/docs/games/troubleshoot/invalid-login).
</StepperItem>
<StepperItem title="Create a Backup">
Next click the "Backups" panel tab and click "Create Backup"
</StepperItem>
<StepperItem title="Delete Current Save">
Click the "File Manager" tab and delete everything
</StepperItem>
<StepperItem title="Run Reinstall">
Click the "Settings" tab and click the "Reinstall Server" button.
</StepperItem>
</Stepper>
