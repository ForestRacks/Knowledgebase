title: Connect to sFTP with FileZilla
description: Learn how to connect to your server using sFTP with FileZilla.
---

In this article we will show you how to connect using the most popular FTP client; Filezilla!

<Stepper>
<StepperItem title="Login and find server">
First login on [https://panel.forestracks.com](https://panel.forestracks.com) and click on your server. If you cannot login, follow the [Troubleshooting Guide](/games/troubleshoot/invalid-login).
</StepperItem>
<StepperItem title="Go to Settings">
Next click the "Settings" panel tab
</StepperItem>
<StepperItem title="Download FileZilla">
Download the [Filezilla Client](https://filezilla-project.org/download.php) application from FileZilla's website
</StepperItem>
<StepperItem title="Quick Connect">
Use the information from our web-panel to signin on the quick connect bar:
* The "Host" input on FileZilla should be the "SERVER ADDRESS" from the ForestRacks "Settings" tab without the port so the Server Address `sftp://node.example.com:2022` should be the FileZilla host `sftp://node.example.com`
* The username input on FileZilla should be the username listed under the Server Address titled "USERNAME"
* The sFTP port on FileZilla should be `2022`
* Your password for FileZilla is your ForestRacks account password
</StepperItem>
</Stepper>

Don't hesitate to [Contact Us](/about/contact-us) if you need assistance with this process, we will also post a video tutorial and screenshots here in future.
