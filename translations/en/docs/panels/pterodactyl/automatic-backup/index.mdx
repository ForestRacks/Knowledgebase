---
title: Schedule Automatic Backups in Pterodactyl Panel
description: Set up automated server backups in Pterodactyl using cron schedules. Protect your game server data with scheduled backup tasks in minutes.
---

<Stepper>
<StepperItem title="Log into Panel">
First login on [https://panel.forestracks.com](https://panel.forestracks.com) and click on your server. If you cannot login, follow the [Troubleshooting Guide](/docs/games/troubleshoot/invalid-login).

</StepperItem>
<StepperItem title="Locate Cron Schedule">
1. Next click the "Schedules" panel tab
2. Click the "Create schedule" button
3. Set a schedule name
4. Input the cron timing, if you are new to cronjobs, click "Show Cheatsheet" or use the [Cronjob Creator](https://crontab.guru/)
5. Click the "New Task" button
6. Select "Create backup" from the action dropdown
7. Click "Create Task" to save

</StepperItem>
</Stepper>
