---
title: Retrieve user data from Discord's API
description: Learn how to retrieve user data from Discord's API using a user ID.
---

Create a bot on [Discord's Developer Application Portal](https://discord.com/developers/applications) and retrieve a bot token.

Below is an example of how to use Discord's API with curl but it may be different depending on how you send the HTTP GET request. Replace `BOT_TOKEN_HERE` with the bot token you just created and fill in the user ID:
```bash
curl -H "Authorization: Bot BOT_TOKEN_HERE" https://discord.com/api/v10/users/USER_ID_HERE
```
