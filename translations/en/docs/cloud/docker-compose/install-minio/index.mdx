---
title: Deploy MinIO with Docker Compose - S3 Object Storage
toc: "Install MinIO"
description: Set up self-hosted S3-compatible object storage using MinIO and Docker Compose. Includes web console access, persistent volumes, and API configuration.
---

```yml:docker-compose.yml
services:
  minio:
    image: minio/minio
    command: server /data --console-address ":9001"
    environment:
      - MINIO_ROOT_USER=your_access_key_here
      - MINIO_ROOT_PASSWORD=your_secret_key_here
    volumes:
      - ./data:/data
    ports:
      - 9000:9000
      - 9001:9001

volumes:
  minio_data:
```

### Start Docker Compose
```bash
docker compose up -d
```
