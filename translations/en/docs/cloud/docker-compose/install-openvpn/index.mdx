---
title: Deploy OpenVPN with Docker Compose - VPN Server Setup
toc: "Install OpenVPN"
description: Set up a self-hosted OpenVPN server using Docker Compose. Automated installation with client profile generation for secure remote network access.
---

```docker:Dockerfile
FROM ubuntu:latest

WORKDIR /root

RUN apt update && apt install -y curl

# Download the installer
RUN curl -O https://raw.githubusercontent.com/angristan/openvpn-install/master/openvpn-install.sh && \
  chmod +x openvpn-install.sh

# Set environment variables
ENV AUTO_INSTALL=y
ENV APPROVE_INSTALL=y
ENV APPROVE_IP=y
ENV MENU_OPTION='1'
ENV CLIENT='{{ client }}'
ENV PASS='1'

# Run installation installer
RUN ./openvpn-install.sh
RUN rm -f openvpn-install.sh
RUN echo "Done, please download your profile"
```

```yml:docker-compose.yml
services:
  openvpn:
    build: .
```

### Start Docker Compose
```bash
docker compose up -d
```
