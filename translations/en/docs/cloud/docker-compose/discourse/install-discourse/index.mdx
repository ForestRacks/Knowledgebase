## Create Working Directory:
```bash
mkdir -p /var/discourse
```

## Clone Discourse Repository:
```bash
git clone https://github.com/discourse/discourse_docker.git /var/discourse
```

## Run Discourse Installer:
```bash
/var/discourse/discourse-setup
```
